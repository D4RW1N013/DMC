# DMC

## DMC — Digital Machine Companion

DMC is a local AI computer agent designed to understand natural-language
commands and perform tasks on a computer.

### Features

- Local LLM through Ollama
- Tool-based computer control
- File system operations
- Network operations
- Python execution
- Web access
- Persistent memory
- Chat interface
- GitHub integration

### Requirements

- Python 3.11+
- Ollama
- Qwen3 8B or another compatible model

### Start DMC

```bash
python -m dmc
```

### Windows

Run `install_dmc_windows.bat`.

### macOS

Run `./install_dmc_macos.sh`.

## Security

DMC can execute computer actions through registered tools.
Potentially dangerous actions require confirmation.
